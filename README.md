# 牛客刷题日程（CodeAgenda）

一个**完全本地运行**的网页小工具：记录每天在牛客上刷的题数、是否完成「每日一题」，并用 GitHub 风格的绿色热力图按年分页展示打卡情况。数据保存在本地 SQLite，不联网、不上传，备份与隐私都自己掌控。

## 功能特性

- **日常记录**：每天记录「普通刷题数量」（非负整数）与「每日一题」完成状态，两者相互独立。
- **今日快捷栏**：一键「过题数 +1」、一键勾选/取消今天的每日一题。
- **统计卡**：累计刷题、单日最高（含日期）、每日一题连续打卡天数、连续刷题天数。
- **两套热力图**：
  - 「刷题足迹」——按当天普通刷题数量分档上色（浅灰 → 四档绿）；
  - 「每日一题足迹」——当天是否完成每日一题。
- **按年分页、可补记**：每年一页，1 月至 12 月从左到右；每月是一块 7 列小日历（列对应周一..周日）。可翻回往年任意一天补记，未来日期灰显不可点。
- **悬停提示 / 点击编辑**：鼠标悬停方块显示日期与题数；点击日期即可编辑当天记录。
- **导出 / 导入**：一键把全部记录导出为 JSON 备份，或从备份恢复（换机 / 迁移用）。
- **自定义页面背景**：上传本地图片作为背景，立即生效、自动保存，可随时恢复默认。
- **牛客账号设置**：设置面板预留账号密码存储位，供后续功能扩展。

## 技术栈

- **后端**：Python 3 + Flask + SQLite（单文件 `app.py`）
- **前端**：原生 HTML / CSS / JavaScript（无框架、无构建步骤）
- **依赖**：仅 Flask

## 快速开始

```bash
# 1. 克隆并进入项目
git clone https://github.com/WithRain0119/CodeAgenda.git
cd CodeAgenda

# 2. 安装依赖（一次性）
python -m pip install flask

# 3. 启动服务
python app.py

# 4. 浏览器打开
#    http://127.0.0.1:5000
```

换端口：用环境变量指定，例如

```bash
PORT=5001 python app.py
```

然后访问 `http://127.0.0.1:5001`。

## 数据存储与隐私

- 全部数据（刷题记录、背景设置、账号信息）存放在项目根目录的 `records.db`（首次启动自动创建）。
- `records.db` 已被 `.gitignore` 排除，**不会**被提交到 GitHub——即使公开仓库，你的记录与账号密码也不会泄露。
- 想重置数据：关闭服务后删除 `records.db`，下次启动会自动重建空库。

## 使用说明

### 记录与统计规则

- **普通刷题数量**：当天普通刷的题目数（非负整数，可为 0）。
- **牛客「每日一题」**：当天是否完成每日一题（独立勾选，不影响刷题数量）。
- **删除当天记录**：把某天普通刷题数量填成 0，且不勾选「每日一题」，等于清除当天记录。
- **连续打卡（每日一题）**：从「今天」往前，连续完成每日一题的天数；今天未完成即为 0。
- **连续刷题**：从「今天」往前，普通刷题数量 > 0 的连续天数；今天未刷即为 0。

### 热力图

- **按年分页**：每页一整年，1 月至 12 月从左到右排列；每月是一块 7 列的小日历（列对应周一..周日，行是该月第几周），月与月之间仅用留白分隔。
- 左上角显示当前年份，用 `‹` / `›` 翻到过去年份补记；当年页面只显示到本月为止，今天之后的日期为浅灰格、不可点。
- **颜色按当天普通刷题数量分档**：0 → 浅灰、1–2 → 浅绿、3–5 → 中绿、6–9 → 深绿、≥10 → 最深绿；是否完成每日一题不影响颜色。
- 鼠标悬停方块会显示日期与题数；点击今天及更早的方块可编辑当天记录。

### 背景图片

在「设置 → 通用」中选择本地图片，上传后立即作为页面背景并自动保存，下次进入仍是该背景。仅支持常见图片格式，大小不超过 20MB，只保留最新一张；「恢复默认」可回到默认白色背景。

### 导出 / 导入

页面底部的「导出备份」把所有记录导出为一个 JSON 文件；「导入数据」读取备份文件并覆盖式合并（按日期 upsert），用于换机或存档。导入不做「清除」规则，保证备份还原的完整性。

## 接口一览

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/` | 页面 |
| GET | `/api/records` | 读取全部记录 |
| POST | `/api/records` | 保存某天记录（count=0 且 is_daily=0 时删除该天） |
| GET | `/api/summary` | 统计汇总（累计 / 单日最高 / 连登天数） |
| GET | `/api/export` | 导出全部记录为 JSON |
| POST | `/api/import` | 导入 JSON 备份 |
| GET | `/api/settings` | 读取设置（牛客账号、外观） |
| POST | `/api/settings/nowcoder` | 保存牛客账号密码（仅本地） |
| POST | `/api/background` | 上传背景图片 |
| DELETE | `/api/background` | 清除背景图片 |

## FAQ

- **端口被占用 / 想换端口**：见上文「换端口」示例。
- **提示缺少 Flask**：执行 `python -m pip install flask`。
- **误删记录**：如果你提前导出过备份，可通过「导入数据」恢复。

# 牛客刷题日程（CodeAgenda）

一个**完全本地运行**的网页小工具：记录每天在牛客上通过的题目、是否完成「每日一题」，并用 GitHub 风格的绿色热力图按年分页展示打卡情况。数据保存在本地 SQLite，不联网、不上传，备份与隐私都自己掌控。

## 功能特性

- **按题记录**：每通过一道题记一条「题目名称 + 题目链接」；当天刷题数 = 当天不重复通过的题目数，同一题重复提交只算一次。
- **今日快捷栏**：在热力图上点选任意一天后，可一键切换该天的「每日一题」状态，或用「添加题目」「删除题目」维护当天已通过的题目。
- **已通过题目列表**：列出所选日期当天通过的每道题——提交时间、题名（可点击跳转）以及是否就是当天的「每日一题」。
- **统计卡**：累计刷题、单日最高（含日期）、每日一题连续打卡天数、连续刷题天数。
- **两套热力图**：
  - 「刷题足迹」——按当天刷题数量分档上色（浅灰 → 四档绿）；
  - 「每日一题足迹」——当天是否完成每日一题。
- **按年分页、可补记**：每年一页，1 月至 12 月从左到右；每月是一块 7 列小日历（列对应周一..周日）。可翻回往年任意一天补记（最早 2000 年），未来日期灰显不可点。
- **悬停提示 / 点击选中**：鼠标悬停方块显示日期与题数；点击方块把该天设为当前操作日期，快捷栏、已通过题目列表随之切换。
- **导出 / 导入**：一键把全部记录导出为 JSON 备份，或从备份恢复（换机 / 迁移用）。
- **自定义页面背景**：上传本地图片作为背景，立即生效、自动保存，可随时恢复默认。
- **牛客自动同步**：配合根目录的用户脚本，在牛客页面自动记录通过的题目与每日一题状态（见下文）。

## 技术栈

- **后端**：Python 3 + Flask + SQLite（单文件 `app.py`）
- **桌面端**：PyQt6 托盘程序 `tray.py`（启动 / 关闭后端、日志窗口、提示卡）
- **前端**：原生 HTML / CSS / JavaScript（无框架、无构建步骤）
- **依赖**：Flask + PyQt6，见 `requirements.txt`

## 快速开始

```bash
# 1. 克隆并进入项目
git clone https://github.com/WithRain0119/CodeAgenda.git
cd CodeAgenda

# 2. 安装依赖（一次性）
python -m pip install -r requirements.txt

# 3. 启动服务
python app.py

# 4. 浏览器打开
#    http://127.0.0.1:5000
```

首次启动会自动创建 `data/` 目录并建表，无需手动初始化。

### Windows 托盘启动（推荐）

双击项目根目录的 `CodeAgenda.bat`（或 `CodeAgenda.vbs`）即可同时启动 Flask 后端和托盘程序，启动过程中不会显示命令行窗口，托盘图标出现后会弹出一张「监控已开启」提示卡。

托盘菜单提供「打开前端网页」「打开日志界面」「关闭程序」三个操作，单击托盘图标也会打开网页。日志窗口展示本次启动以来后端的标准输出和错误输出；关闭程序会同时停止后端。程序使用 `.codeagenda.lock` 文件锁防止重复启动，重复双击只会提示「监控已开启，无需重复启动」，不会启动第二个后端。

> 双击没反应时，先看根目录的 `tray_debug.log`；启动依赖 `pythonw.exe` 在 `PATH` 中。

## 牛客自动同步（Tampermonkey）

项目根目录的 [`nowcoder_sync.user.js`](nowcoder_sync.user.js) 是可直接导入 Tampermonkey 的用户脚本。先启动本地 Flask 服务，再在 Tampermonkey 中新建脚本并粘贴该文件内容。脚本会在 `https://www.nowcoder.com/*` 页面上：

- 识别「每日一题」的已完成状态，并同步当天 `is_daily=1`；
- 识别提交结果中的「答案正确 / Accepted / AC」等成功提示，把当天通过的题目写入明细；
- 只有检测到本次点击“提交/运行”或按下 `Ctrl/Cmd+Enter` 后的成功结果才会计数，页面中原有的历史 Accepted 提示不会自动计数；
- 每次写入前先读取 `/api/records` 并合并字段，不覆盖另一项记录；
- 每道提交题目是否已经计数完全以 CodeAgenda 本地 `submissions` 数据库为准；同一道题当天重复提交不会重复计数，而以前在牛客做过、但数据库中没有的题目，首次在系统运行期间提交通过时会正常计数。

主页面每 5 秒轮询一次后端，所以牛客那边同步成功后，回到页面即会自动显示最新题目。

打开浏览器控制台可查看 `[CodeAgenda]` 日志。脚本默认开启调试日志：执行 `window.syncHelper.debugDaily()` 会打印每日一题候选元素及最终判断，执行 `window.syncHelper.debugAC()` 会打印 AC 候选文本；执行 `window.syncHelper.setDebug(false)` 可关闭调试日志。`mockDaily()`、`mockAC()` 和 `scan()` 可用于手动测试同步。如果牛客改版导致识别不到状态，优先根据候选日志调整用户脚本中的 `isDailyComplete()` 和 `acSignal()` 文本匹配规则。

### 换端口

用环境变量指定，例如

```bash
PORT=5001 python app.py
```

然后访问 `http://127.0.0.1:5001`。注意托盘程序（`CODEAGENDA_URL`）与用户脚本（`API_BASE`）默认都连 `127.0.0.1:5000`，换端口后需要同步改这两处。

## 数据存储与隐私

- 全部数据存放在项目根目录的 `data/` 下（首次启动自动创建）：
  - `data/records.db`——每天的汇总记录（题数、是否完成每日一题）与设置（牛客账号、背景图片路径）；
  - `data/details.db`——每道通过题目的明细、以及每天的每日一题题名与链接。
- `data/*.db`、`static/backgrounds/*`、`.codeagenda.lock`、`tray_debug.log` 均已被 `.gitignore` 排除，**不会**被提交到 GitHub——即使公开仓库，你的刷题记录也不会泄露。
- 旧版本遗留在项目根目录的 `records.db` 会在启动时自动迁移进 `data/`，迁移后即可手动删除。
- 「牛客账号设置」里的密码以**明文**存放在本地 `records.db` 中，仅本机使用、不会上传；请不要在这台机器上存放你其它平台在用的密码。
- 想重置数据：关闭服务后删除 `data/` 目录，下次启动会自动重建空库。

## 使用说明

### 记录与统计规则

- **刷题数量怎么来的**：每记一道通过的题目即为当天 +1 题；某天的题数由该天已通过题目按题目链接去重后得出。手动添加和用户脚本自动同步写入的是同一份明细。
- **牛客「每日一题」**：既可以在页面上手动勾选，也会在同步脚本识别到牛客「每日一题」已完成时自动置位。后端还会拿当天每日一题的链接与当天通过的题目比对，命中的那道题会带上「每日一题」标签。
- **删除题目**：在「删除题目」列表中逐条删除；删掉某天最后一题后，该天题数归零。
- **连续打卡（每日一题）**：从「今天」往前，连续完成每日一题的天数；今天未完成即为 0。
- **连续刷题**：从「今天」往前，刷题数量 > 0 的连续天数；今天未刷即为 0。

### 热力图

- **按年分页**：每页一整年，1 月至 12 月从左到右排列；每月是一块 7 列的小日历（列对应周一..周日，行是该月第几周），月与月之间仅用留白分隔。
- 左上角显示当前年份，用 `‹` / `›` 翻到其它年份补记（最早 2000 年，有更早记录时以记录年份为准；不能翻到未来年份）；当年页面中今天之后的日期为浅灰格、不可点。
- **颜色按当天刷题数量分档**：0 → 浅灰、1–2 → 浅绿、3–5 → 中绿、6–9 → 深绿、≥10 → 最深绿；是否完成每日一题不影响颜色。
- 鼠标悬停方块会显示日期与题数；点击今天及更早的方块会把它设为当前操作日期（今天用深色描边、当前选中日期另有标记）。

### 背景图片

在「设置 → 通用」中选择本地图片，上传后立即作为页面背景并自动保存，下次进入仍是该背景。仅支持常见图片格式，大小不超过 20MB，只保留最新一张；「恢复默认」可回到默认白色背景。

### 导出 / 导入

页面底部的「导出备份」把所有记录（每日汇总 + 题目明细 + 每日一题）导出为一个 JSON 文件；「导入数据」读取备份文件并覆盖式合并（按日期 upsert），用于换机或存档。导入不做「清除」规则，保证备份还原的完整性。

## 项目结构

```
.
├── app.py                    # Flask 后端 + SQLite（单文件）
├── tray.py                   # PyQt6 托盘程序：启动 / 关闭后端、日志窗口、提示卡
├── CodeAgenda.bat            # 双击启动入口（转调 vbs）
├── CodeAgenda.vbs            # 用 pythonw.exe 无窗口拉起 tray.py
├── requirements.txt          # Python 依赖（Flask + PyQt6）
├── nowcoder_sync.user.js     # Tampermonkey 用户脚本（牛客页面自动同步）
├── templates/
│   └── index.html            # 页面结构（统计卡 / 快捷栏 / 热力图 / 弹窗 / 设置面板）
├── static/
│   ├── app.js                # 前端逻辑（渲染、交互、请求）
│   ├── style.css             # 样式（GitHub 浅色风格）
│   ├── favicon.svg           # 站点图标（同时作为托盘图标）

    ├── records.db            # 每日汇总记录 + 设置
    └── details.db            # 通过题目明细 + 每日一题
```

## 接口一览

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/` | 页面 |
| GET | `/api/records` | 读取全部记录 |
| POST | `/api/records` | 保存某天记录（count=0 且 is_daily=0 时删除该天） |
| GET | `/api/submissions` | 读取已通过题目（可带 `?date=YYYY-MM-DD` 只看某天） |
| POST | `/api/submissions` | 记录当天一道已通过题目（按题目链接的主机 + 路径幂等去重） |
| DELETE | `/api/submissions/<id>` | 删除一条已通过题目，并重算当天记录 |
| GET/POST | `/api/daily-problems` | 读取或保存当天的每日一题（题名与链接） |
| GET | `/api/summary` | 统计汇总（累计 / 单日最高 / 连登天数） |
| GET | `/api/export` | 导出全部记录为 JSON |
| POST | `/api/import` | 导入 JSON 备份 |
| GET | `/api/settings` | 读取设置（牛客账号、外观） |
| POST | `/api/settings/nowcoder` | 保存牛客账号密码（仅本地） |
| POST | `/api/background` | 上传背景图片 |
| DELETE | `/api/background` | 清除背景图片 |

## FAQ

- **端口被占用 / 想换端口**：见上文「换端口」示例。
- **提示缺少 Flask 或 PyQt6**：执行 `python -m pip install -r requirements.txt`。
- **双击 `CodeAgenda.bat` 没反应**：确认 Python 已加入 `PATH`（需要 `pythonw.exe`），并查看根目录的 `tray_debug.log`。
- **同步脚本连不上**：确认后端已在 `127.0.0.1:5000` 运行；改过端口的话，脚本里的 `API_BASE` 也要一起改。
- **牛客改版后同步失灵**：按控制台 `[CodeAgenda]` 日志调整 `nowcoder_sync.user.js` 中的 `isDailyComplete()` / `acSignal()` 匹配规则。
- **误删记录**：如果你提前导出过备份，可通过「导入数据」恢复。

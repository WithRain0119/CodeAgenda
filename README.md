# 牛客刷题记录（本地网页工具）

一个完全本地运行的小工具，用来记录每天在牛客上刷的题数、是否完成「每日一题」，并用 GitHub 绿色风格的热力图按年分页展示打卡情况。数据保存在本地 SQLite，不联网、不云同步。

## 启动步骤

```bash
# 1. 安装依赖（一次性；已装可跳过）
python -m pip install flask

# 2. 启动服务
python app.py

# 3. 浏览器打开
#    http://127.0.0.1:5000
```

## 数据存储

数据存放于项目根目录的 `records.db`（首次启动自动创建）。想重置全部数据，关闭服务后删除该文件即可，下次启动会自动重建空库。

## 记录规则

- **普通刷题数量**：当天普通刷的题目数（非负整数，可为 0）。
- **牛客「每日一题」**：当天是否完成了牛客每日一题（勾选）。
- **删除**：把某天的普通刷题数量填成 0 且不勾选「每日一题」= 清除当天记录。
- **连续打卡（streak）**：从「今天」往前，连续勾选了「每日一题」的天数；今天未勾选即为 0（与刷题数量无关）。

## 热力图

- **按年分页**：每页是一整年，从左到右依次为 `1月..12月` 排列，**每个月是一块 7 列的小日历**（列对应周一..周日，行是该月的第几周），每一天按其「周几」落在对应列；块与块之间仅用留白分隔。
- 左上角显示当前年份，可用 `‹` / `›` 翻到以前年份（可补记过去任意一天）；当年页面只显示到本月为止，今天之后的日期为浅灰格、不可点。
- 每个方块的**颜色按当天普通刷题数量分档**：0 → 浅灰、1–2 → 浅绿、3–5 → 中绿、6–9 → 深绿、≥10 → 最深绿；是否勾选「每日一题」不影响颜色。
- 鼠标悬停方块会显示日期与题数提示；点击（今天及更早）方块可编辑当天记录。

## 导出 / 导入

页面底部的「导出备份 / 导入数据」用于把全部记录导出为一个 JSON 文件、或把备份文件重新导入（供将来云同步 / 换机备份使用）。

## FAQ

- **端口被占用 / 想换端口**：用环境变量指定，如

  ```bash
  PORT=5001 python app.py
  ```

  然后浏览器访问 `http://127.0.0.1:5001`。
